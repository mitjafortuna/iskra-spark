Privacy Policy – Iskra Spark Uploader

Last updated: 22 October 2026

Iskra Spark Uploader ("the tool") is a private command-line tool used only by the owner of the YouTube channel "Iskra & Spark - Space for Kids" (@IskraAndSpark) to upload and manage the channel's own videos.

YouTube API Services

The tool uses YouTube API Services. By using the tool you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

What data the tool accesses

With the owner's permission (Google OAuth, scopes youtube and youtube.upload), the tool accesses only the owner's own YouTube channel: channel information, the channel's videos, playlists and thumbnails. It uses this data only to upload videos, set their details and thumbnails, add them to the channel's playlists and schedule them.

The tool does not access, collect or store data about any other person, including viewers of our videos. It does not use cookies or tracking.

Storage

The only data stored by the tool is the OAuth sign-in token, kept in a file on the owner's own computer. It is never sent anywhere except to Google.

Sharing

No data is sold, shared or passed to third parties.

Deleting data and revoking access

  • Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions.
  • When access is revoked, or on request, the stored token file is deleted from the owner's computer. No other copies exist.
  • Videos uploaded with the tool can be deleted at any time in YouTube Studio.
  • Requests about data can be sent to kidscartoonondemand@gmail.com and are answered within 7 days.

Children

Our videos are made for children and are marked "Made for kids" on YouTube. The tool itself is used only by the adult channel owner and collects no data from children.

Changes

Changes to this policy are published on this page with a new "Last updated" date.
